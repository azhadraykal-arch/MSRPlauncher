# MNRP Launcher
1. Buka folder ini di Android Studio (Hedgehog atau lebih baru), tunggu Gradle sync.
2. Edit `app/src/main/java/com/mnrp/launcher/Config.kt` (IP, port, Discord, package client, link unduh).
3. Jika package client berbeda, ubah juga `<queries><package .../>` di AndroidManifest.xml.
4. Build > Build APK(s).
Launcher ini hanya aplikasi pendamping; client game harus dari sumber resmi/berlisensi.
